# ULTRATHINK

Activate the ULTRATHINK protocol for deep, multi-dimensional analysis of the current task.

## Instructions

Load and apply the ULTRATHINK behavioral directive from `pmoves/configs/agent-prompts/ultrathink.md`.

When ULTRATHINK is active:

1. **Suspend brevity rules** — provide exhaustive reasoning
2. **Analyze through all lenses:**
   - Psychological: user sentiment and cognitive load
   - Technical: performance, state complexity, rendering costs
   - Accessibility: WCAG AAA strictness
   - Scalability: long-term maintenance and modularity
   - CHIT Geometry: GEOMETRY BUS connections, CGP packet relevance
   - Agent Orchestration: which agents coordinate, NATS subjects involved
3. **Never use surface-level logic** — dig until irrefutable
4. **Design Philosophy:** Intentional Minimalism — anti-generic, bespoke, purposeful
5. **Library Discipline:** Use existing UI libraries (Radix, Shadcn), never rebuild primitives
6. **Response format:**
   - Deep Reasoning Chain
   - Edge Case Analysis
   - CHIT Connection
   - Agent Coordination
   - The Code (optimized, production-ready)
