# PMOVES Node Registry Service Dependencies

#

#   supabase     -> storage.py (SupabaseNodeStore; InMemoryNodeStore is the

#                   dependency of the Supabase-backed mode, not of import)
#
# The shared modules the image also carries (services/common,
# services/resource_detector) import only the standard library at import
# time, so they add nothing here.
