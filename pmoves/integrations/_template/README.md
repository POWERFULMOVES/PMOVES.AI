# Integration Template

Use this template to create a new integration overlay in PMOVES or inside a submodule (`pmoves-integrations/`).

- Contract: `pmoves/docs/SUBMODULE_INTEGRATION_CONTRACT.md`
- Model source of truth: `pmoves/docs/MODEL_SOURCE_OF_TRUTH.md`
- Validation toolkit: `pmoves/tools/submodule_integrity.py` + `pmoves/tools/submodule_sitrep.py` + `pmoves/tools/integration_contract_check.py`
