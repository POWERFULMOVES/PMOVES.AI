# Firefly & Wger Integration Status Review
_Last updated: 2026-03-11_

## Overview
- Compose profiles for Firefly III, Wger, and the flows watcher are checked into `pmoves/compose/`.
- Credential auto-generation added via `brand_defaults.py`: `FIREFLY_APP_KEY`, `WGER_API_TOKEN`, `N8N_ENCRYPTION_KEY`, `N8N_RUNNERS_AUTH_TOKEN`.
- n8n workflow overlays in `pmoves/integrations/health-wger/n8n/flows/` and `pmoves/integrations/firefly-iii/n8n/flows/` with cross-domain workflows.
- FlOOS pipelines (`health-sync`, `finance-sync`) defined in `skill-pairings.yaml`.

## Firefly III profile
- `pmoves/compose/docker-compose.firefly.yml` defines a MariaDB-backed Firefly III stack.
- Default port: `FIREFLY_PORT=8075` (avoids Agent Zero API conflict on 8080).
- `FIREFLY_APP_KEY` auto-generated by `brand_defaults.py` (Laravel format: `base64:` + 32 random bytes).
- Database credentials fall back to weak defaults unless overridden.
- `make smoke-firefly` exercises the login landing page plus `/api/v1/about`.
- **Mobile**: Waterfly III (unofficial) connects via REST API at `http://<host>:8075/api/v1/`.

## Wger profile
- `pmoves/compose/docker-compose.wger.yml` provisions Postgres 15 + PMOVES-tagged Wger image.
- Port: `8000/tcp`.
- `WGER_API_TOKEN` auto-generated by `brand_defaults.py` with `pm_wger_` prefix.
- Brand defaults via `scripts/wger_brand_defaults.sh` + `WGER_BRAND_*` env vars.
- Admin password defaults to `adminadmin` on fresh bootstrap — rotate via UI or Django mgmt commands.
- OpenAPI schema at `pmoves/docs/services/wger/wger.yaml`.
- **Mobile**: Official Wger Flutter apps (Android/iOS) connect via REST API at `http://<host>:8000/api/v2/`.

### Cross-Domain Workflows
- **health_to_research.json**: Triggers DeepResearch when health anomaly detected. Fetches recent workout context from Wger, sends to DeepResearch API.
- **finance_health_crosswalk.json**: Daily correlation of health supplement purchases (Firefly) with workout performance (Wger). Stores crosswalk data in Supabase.
- **voice_health_checkin.json**: Daily voice-prompted health check-in via Flute-Gateway prosodic synthesis. Checks last workout from Wger, notifies via Discord.
- **integration_status_reporter.json**: 6-hour health dashboard checking Wger, Firefly III, and NATS endpoints. Posts status report to Discord.
