The 5 Dimensions of a CHIT Packet

Every piece of music, every agent state, every thought gets encoded as five numbers. These five numbers can represent anything.

Symbol Name What it measures In DARKXSIDE Beats Effect when high
δ
 Delta Phase velocity / tree-likeness Tempo BPM (normalized 60–180) More grounding, less generative freedom
κ
 Kappa Hyperbolic curvature Dynamic range (LRA — how much the track breathes) Prefers hierarchical retrieval chains
Hz
 Hertz Spectral entropy / signal character Spectral centroid (bass-heavy → airy) More filtering passes before output
F
 Fitness Swarm / cluster quality Silhouette coherence score of the sonic group Strong group separation → trust the clustering
A
 Attribution Confidence / tonal clarity Spectral flatness inverted (tonal = 1.0, noisy = 0.0) Low A → hold in review before publishing
Where Can You See It?

CHIT geometry flows through the whole PMOVES mesh. Here's the full visibility chain — from beats folder to 3D constellation.

Step 1 — Audio Source
🎵 DARKXSIDE SoundCloud + Google Drive
82 tracks downloaded to pmoves/data/beats/soundcloud/darkxside/. Drive tracks via rclone sync. No files deleted — organized by sound, not overwritten.
Step 2 — Analysis (Cipher Beats Analyst)
🔬 uv run pmoves/tools/analyze_beats.py analyze
ffmpeg lavfi fingerprinting. Auto-escalates from glaze → gaze if signal is ambiguous. Groups outputs M3U8 playlists + fingerprint cache.
pmoves/data/beats/playlists/groups_summary.json
Step 3 — CHIT Translation
⬡ uv run pmoves/tools/beats_to_cgp.py render
Sonic groups → geometry.cgp.v1 NATS events. Each group is a constellation placed on a 3D sphere using tempo + spectral character as coordinates.
NATS: geometry.cgp.v1 | geometry.beats.control.v1
Step 4 — Visualization
🌐 Hyperdimensions — Three.js WebGL
Subscribes to geometry.cgp.v1 via NATS WebSocket. Renders each track as a ConeGeometry (audio modality). Groups orbit different radii based on coherence quality. Auto-rotate, labels, click-to-inspect.
http://localhost:YOUR_HYPERDIMENSIONS_PORT
Step 5 — Live Portal
🔭 Chrome Extension → Hyperdimensions Portal
Open the PMOVES Chrome extension. Click "Hyperdimensions Portal". See δ κ Hz F A live as WebRTC streams CGP packets. The state vector updates live as beats are analyzed.
chrome-extension://[id]/portal/portal.html
Step 6 — Video Export (Coming)
🎬 A2UI Renderer → Remotion 4.0.436
CHIT geometry → Remotion composition → MP4/WebM. Beat-synced using @remotion/sfx. Each sonic group becomes an animated holographic block for video content, Jellyfin playlists, or streaming overlays.
