# TAC_GATEWAY_AGENT
_Last updated: 2026-03-15_

## Mission

Route MCP tool calls across the PMOVES orchestration layer. The Gateway Agent provides a unified entry point for tool execution, dispatching requests to the appropriate backend (Agent Zero, Archon, BoTZ) based on capability matching and load balancing.

## Current State

- **Port:** 8100
- **Team:** Orchestration (agent-teams.yaml)
- **Dependencies:** Agent Zero (8080), Archon (8091), BoTZ Gateway (8054), NATS (4222)
- **Auth:** `MCP_CLIENT_SECRET` (auto-generated by `brand_defaults.py`)

## Architecture

```
  External MCP Clients
         │
         ▼
   Gateway Agent (8100)
    ┌─────┼─────────┐
    │     │         │
    ▼     ▼         ▼
  Agent  Archon    BoTZ
  Zero   (8091)   Gateway
 (8080)            (8054)
    │     │         │
    └─────┼─────────┘
          │
          ▼
      NATS Bus
   (tool execution events)
```

## Tool Routing

| Backend | Capabilities | Priority |
|---------|-------------|----------|
| Agent Zero | Orchestration, task delegation, subordinate model | Primary |
| Archon | Supabase queries, prompt management, form CRUD | Domain-specific |
| BoTZ Gateway | 100+ MCP tools, skill marketplace, community plugins | Breadth |

## Auth Model

| Component | Mechanism |
|-----------|-----------|
| `MCP_CLIENT_SECRET` | Shared secret for external clients (auto-generated) |
| `MCP_CLIENT_ID` | Client identifier |
| Internal routing | Network isolation (Docker network) |
| JWT validation | Via Supabase JWT when proxying authenticated requests |

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `MCP_CLIENT_SECRET` | Auto-generated | Shared secret for MCP API |
| `MCP_SERVICE_URL` | `http://agent-zero:8080/mcp` | Primary MCP backend |
| `AGENTZERO_JETSTREAM` | `true` | Reliable NATS delivery |

## Phases

1. **Authenticate** — Validate `MCP_CLIENT_SECRET` or JWT
2. **Discover** — Query capability registry for matching tools
3. **Route** — Dispatch to best-match backend
4. **Execute** — Backend processes tool call
5. **Return** — Relay result to caller
6. **Observe** — Emit `claude.code.tool.executed.v1` for observability

## NATS Subjects
