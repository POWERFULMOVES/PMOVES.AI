PMOVES.AI Help

Quick reference for the Chrome Extension

Dashboard (Popup)

Health Grid

8 dots showing service status. healthy, down, unknown. Latency shown below each dot.

GPU Panel

VRAM usage bar, temperature, utilization, loaded model count. Click Optimize VRAM to free memory.

YouTube Ingest

Paste a YouTube URL and click Ingest to queue it for transcription and indexing.

RAG Search

Type a question, click Search. Results come from Hi-RAG v2 (vector + graph + full-text).

Chat with AI

Ask anything via TensorZero gateway. Uses Claude or other configured models.

Text-to-Speech

Type text, click Speak. Synthesized via Flute Gateway with prosodic emphasis.

Agent Tasks

Describe a task for Agent Zero. It uses MCP tools to complete complex multi-step operations.

CHIT Pipeline

Run full geometry analysis on a video, or decode constellation IDs. Browse shapes with SVG links.

Press Enter in any input field to trigger the action button.

YouTube Features

Floating Button (bottom-right)

A purple circle appears on YouTube pages with 8 menu items:

  1. Process Current Video — ingest the video you're watching
  2. Search Knowledge — opens a Hi-RAG search overlay
  3. Summarize with AI — AI summary of the video
  4. Read Aloud — TTS of the video title
  5. Process All on Page — queue every video on the page
  6. Monitor Channel — track the channel for new content
  7. Processing History — view past jobs
  8. Settings — open extension settings

Thumbnail Buttons

Hover over any video thumbnail to see a small PMOVES.AI icon. Click to process that video.

GPU Badge

The floating button shows a colored badge with GPU utilization: <70%, 70-90%, >90%.

Press Escape to close any overlay or modal.

Settings

Service Endpoints

Default URLs point to localhost. Change only if your services run elsewhere. Use the Test button to verify each.

Authentication

  • Agent Zero Token — from your .env (AGENTZERO_API_TOKEN)
  • Flute API Key — optional, from Flute .env (FLUTE_API_KEY)

Feature Toggles

  • Auto-process — automatically ingest videos on page load (off by default)
  • Floating button — the purple circle on YouTube (on by default)
  • Thumbnail buttons — icons on video hover (on by default)
  • Notifications — desktop alerts for events (on by default)
