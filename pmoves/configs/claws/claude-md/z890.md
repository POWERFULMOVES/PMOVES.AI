# PMOVES.AI — Z890 Development Workstation

**Role:** Full infrastructure — development, Docker, all services, GPU workloads
**Model:** claude-opus-4 (full profile, auto-approve)

This node has full access to the entire PMOVES.AI platform. See the main CLAUDE.md at `.claude/CLAUDE.md` for the complete service catalog, API reference, and development patterns.

## Quick Reference

```bash
# Service health
make -C pmoves verify-all

# Start services
make -C pmoves up-all

# Fleet status
make -C pmoves claws-status

# Deploy claw to VPS
make -C pmoves claw-deploy SCOPE=kvm4-1
```
