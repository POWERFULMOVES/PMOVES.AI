## Multi-Boot Awareness (2026-04-21)

Z890 is a **multi-boot workstation**. The active slot determines which toolchain paths apply:

| Slot | Detection | Primary use |
|------|-----------|-------------|
| Windows 11 23H2 | `$env:OS == "Windows_NT"` | Pinokio apps, Docker Desktop, Chrome extension dev |
| Ubuntu 24.04 (partition 5) | `ID=ubuntu` in /etc/os-release | Fleet-parity Linux — matches KVM4-N baseline |
| Pop!_OS 22.04 (partition 6) | `ID=pop` | NVIDIA-preloaded workloads |
| Fedora / Nobara 40 (partition 7) | `ID=fedora` or Nobara signature | RPM-ecosystem services |
| CachyOS (partition 8) | `ID=cachyos` | Performance / bleeding-edge testing |
| NixOS 23.11 (partition 9) | `ID=nixos` | Declarative experiments |

**Identify current slot:**
```bash
# Linux slots
cat /opt/pmoves/profile.yaml | grep '^distro:'
# or
. /etc/os-release && echo "$ID $VERSION_ID"

# Windows slot
$env:OS  # "Windows_NT"
wmic os get Caption
```

**Switch slots:**
Reboot and select from GRUB (Linux peers visible via `os-prober`) or UEFI boot menu (F12 on most BIOS builds). See `deploy/provision/z890/README.md` for the full partition layout and recovery paths.

## Quick Reference

```bash
# Service health
make -C pmoves verify-all

# Start services
make -C pmoves up-all

# Fleet status
make -C pmoves claws-status

# Deploy claw to VPS
make -C pmoves claw-deploy SCOPE=kvm4-1

# Multi-boot bootstrap (fresh install flows)
make -C pmoves z890-media-nvme DEVICE=/dev/nvme0n1     # partition a fresh NVMe
make -C pmoves z890-media-usb DISTRO=ubuntu-24.04 DEVICE=/dev/sdX
make -C pmoves z890-post-install                        # auto-detects current distro
make -C pmoves z890-verify                              # verification sweep
```
