The Stage

PMOVES runs as rooms on a stage — each room a curated workspace an agent can walk into. These are the public rooms, rendered through the A2UI protocol: the cards below are drawn by the real agent-UI renderer from the same message stream an agent would send. Eventually every surface here is spawnable — this is the recommended opening cast.
